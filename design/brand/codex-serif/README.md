# Codex 衬线 V 版本

基于最初 Codex 方案绘制。保留黑金配色、倾斜餐叉与餐匙、开放雷达圆弧及发现点；将圆头折线 V 改为填充字形，增加上端外张衬线、内侧曲线与尖锐下端。餐匙上移 1 个画布单位，为右侧衬线留出空间。

参考范德堡官方标识的上端外张衬线和内侧尖角，重新绘制餐具 V。参考来源：https://brand.vanderbilt.edu/logos-and-lockups/

`icon.svg` 为 64 × 64 画布应用图标；`favicon.svg` 为 32 × 32 画布标签页图标，保留加粗的衬线 V，省略餐具细节。独立标记与完整字标均以路径构成，可任意缩放。
