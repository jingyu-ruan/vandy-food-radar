# 餐叉信标

正式网站采用 2026 年 10 月 3 日选定的餐叉信标方案。
图形由餐叉、向外扩散的信号弧线和发现圆点构成，配色为深灰黑 `#242521` 与金色 `#CFAE70`。

`vfr-icon.svg` 用于页眉，`favicon.svg` 是小尺寸简化版本，`apple-touch-icon.png` 用于主屏幕快捷方式。
`vfr-mark.svg` 与 `vfr-mark-dark.svg` 为透明背景标记；完整字标的文字为矢量路径。

原始草案位于 `design/brand/explorations/beacon/`；原 Codex V 方案保存在 `design/brand/` 中。
